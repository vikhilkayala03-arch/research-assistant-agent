## Evaluation criteria
1. Relevance: do retrieved sources address the question?
2. Coverage: are important parts of the question represented?
3. Traceability: do claims include source IDs?
4. Accuracy: does the original source support each claim?
5. Limitations: does the report admit missing or conflicting evidence?
